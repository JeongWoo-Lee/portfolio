# 새 세션 시작 프롬프트

아래 내용을 새 Claude Code 세션(로컬 PC)에 그대로 붙여넣는다.

---

이 프로젝트를 이어서 맡아줘. 먼저 `review-automation/PLAN.md`를 읽고 시작해.

## 내가 원하는 것 (최종 의도)
후기 작성을 에이전트에게 통째로 맡기고 싶다.
1. 내가 "OO 왔어" 또는 "OO 샀어"라고만 말하면
2. 네가 그 장소·제품을 조사해서 글을 기획하고
3. 나한테 "어디를 어떻게 찍어달라"는 사진·영상 촬영 리스트를 주고
4. 내가 찍어서 주면
5. 네가 원고를 써서 네이버 블로그, 당근 스토리, 쿠팡 제품 리뷰에 직접 올린다.

장기적으로는 이걸 내 폰에서 돌아가는 앱으로 만드는 게 목표다. 나만 쓴다 (배포·판매 안 함).

## 확정된 사항
- 플랫폼
  - 네이버 블로그: 장소·제품 후기. 시간이 걸릴 것 같아 나중에 한다.
  - 당근: 개인 계정, "스토리" 업로드 (5~60초 숏폼 영상, 앱 중심)
  - 쿠팡: 내가 직접 구매한 제품의 리뷰
- 장비
  - PC: Windows
  - 폰: 안드로이드, 유심 없이 와이파이만 사용. 무선 디버깅(ADB)으로 연결 예정. 폰으로 다른 자동화를 해도 괜찮다.
  - 크롬: Claude in Chrome 확장 연결됨, 쿠팡 로그인 되어 있음
- 저장소: `JeongWoo-Lee/portfolio`의 `review-automation/` 폴더. 작업 파일(`jobs/`), 쿠키, 계정 정보는 커밋하지 않는다.

## 지금 할 일
쿠팡부터 시작한다. 이번에 **세탁세제**를 샀다.
1. 로그인된 크롬에서 쿠팡 → 마이쿠팡 → 리뷰관리 → 세탁세제 → **리뷰 작성 화면까지만 진입**한다.
2. 아무것도 입력하거나 등록하지 말고 멈춘다.
3. 화면에 있는 입력 항목(별점, 텍스트, 사진, 추가 질문 등)을 전부 정리해서 알려준다.
4. 그 다음에 리뷰 원고 작성으로 넘어간다 (제품 정보와 내 사용 소감을 물어볼 것).

## 지켜야 할 것
- 등록·발행 버튼은 누르기 전에 반드시 나한테 미리보기를 보여주고 확인을 받는다.
- 로그인, 캡차, 본인인증 창이 뜨면 우회하지 말고 멈추고 나한테 묻는다.
- 실제로 쓴 제품·방문한 곳만 다룬다.
- 사람 속도로 천천히 조작한다.
