# 후기 작성 자동화 플랜

## 목표

"어디 왔어 / 뭐 샀어" 한마디로 시작해서 에이전트(Claude Code)가 끝까지 진행한다.

```
[사용자] "OO식당 왔어" / "쿠팡에서 OO 샀어"
   ↓
1. 조사·기획   에이전트가 장소/제품을 조사하고 글 구성을 짠다
   ↓
2. 촬영 요청   "간판 정면 1장, 대표메뉴 위에서 1장, 매장 분위기 10초 영상…" 촬영 리스트 전달
   ↓
[사용자] 촬영 후 전달 (폰에 찍어두기만 하면 에이전트가 가져감)
   ↓
3. 원고 작성   네이버 블로그 / 당근 스토리 / 쿠팡 리뷰 원고 + 사진 순서
   ↓
4. 확인        사용자에게 미리보기 → OK
   ↓
5. 업로드      블로그 발행, 당근 스토리 업로드, 쿠팡 리뷰 등록
```

| 플랫폼 | 대상 | 업로드 경로 |
|---|---|---|
| 네이버 블로그 | 장소·제품 후기 | 안드로이드 앱 또는 PC 크롬 |
| 당근 스토리 | 장소 후기 숏폼 (5~60초 영상) | 안드로이드 앱 |
| 쿠팡 | 직접 구매한 제품 리뷰 | 안드로이드 앱 또는 PC 크롬 |

## 구조

에이전트 = 사용자 PC에서 실행하는 Claude Code.
생각하는 일(조사·기획·원고)은 Claude Code가 하고, 반복 조작만 스크립트로 만든다.
→ Claude Code 구독으로 돌리므로 별도 API 키가 필수는 아니다.

```
사용자 PC
├─ Claude Code (에이전트)
│   └─ .claude/skills/        단계별 작업 지침
│       ├─ review-plan        조사 + 기획 + 촬영 리스트
│       ├─ review-write       원고 작성 (플랫폼별)
│       └─ review-post        업로드 (플랫폼별 스크립트 호출)
├─ scripts/
│   ├─ phone.py               ADB + uiautomator2: 화면 캡처, 탭, 입력, 미디어 가져오기
│   ├─ media.py               사진 리사이즈, 영상 5~60초 자르기 (ffmpeg)
│   ├─ naver_blog.py
│   ├─ daangn_story.py
│   └─ coupang_review.py
└─ jobs/<날짜>-<이름>/         작업 단위 폴더 (커밋 안 함)
    ├─ plan.md  shots.md  media/  draft-*.md  log.md
└─ 같은 와이파이의 안드로이드 폰 (무선 디버깅 ON)
```

## 왜 폰(앱) 중심인가

- 당근 스토리는 앱 전용이라 어차피 폰 조작이 필요하다.
- 실제 기기 + 실제 앱이라, PC 자동화 브라우저보다 봇으로 보일 여지가 적다 (추정, 검증 필요).
  단 유심 없이 집 와이파이를 쓰므로 IP는 PC와 같다.
- 찍은 사진·영상이 이미 폰에 있으므로 옮기는 단계가 줄어든다.
- 단, 앱 화면 구조가 바뀌면 스크립트가 깨진다 → 화면 캡처를 보고 에이전트가 판단하는 방식으로 보완.
- 네이버 블로그는 PC 크롬(스마트에디터 ONE)이 서식 넣기에 더 나을 수 있어 둘 다 시험해 보고 고른다.

## 원칙

- 실행은 사용자 PC + 사용자 폰에서만 한다.
- 발행/등록 직전에 사용자 확인을 받는다 (안정화 후 플랫폼별로 생략 여부 결정).
- 캡차·본인인증은 우회하지 않고, 뜨면 멈추고 사용자에게 요청한다.
- 실제 방문·직접 구매 건만 다룬다. 협찬·제공받은 건은 글에 표기한다.
- 계정 정보·쿠키·작업 폴더는 커밋하지 않는다 (`.gitignore`).
- 동작 속도는 사람 수준으로 (연속 대량 업로드 금지).

## 배경 (조사 결과)

- 네이버 블로그 글쓰기 API는 2020.05 종료. 2025.07부터 자동화 접근 차단 강화.
- 티스토리 Open API 2024.02 종료. 쿠팡·당근은 공개 작성 API 없음.
- 깃허브 사례는 대부분 Playwright/Selenium으로 네이버 PC 에디터 조작, 기본 임시저장 + 캡차 시 정지.

## 단계

### Phase 0. 환경 준비
- [ ] PC에 Claude Code, Python, ADB(platform-tools), scrcpy, ffmpeg 설치
- [ ] 폰 개발자 옵션 → 무선 디버깅 ON (Android 11+), `adb pair` / `adb connect`로 와이파이 연결
- [ ] 유심 없음: 당근 등 SMS 인증이 필요한 재로그인은 다른 폰으로 문자 받아 입력
- [ ] 이 저장소를 PC에 clone
- [ ] 네이버·쿠팡·당근 앱 로그인 상태 확인

### Phase 1. 폰 제어 기본기 (`phone.py`)
- 연결 확인, 스크린샷, 화면 요소 덤프, 탭/스와이프/텍스트 입력(한글)
- 최근 촬영 사진·영상 목록 → PC로 가져오기 / PC 파일 → 폰 갤러리로 넣기

### Phase 2. 기획·촬영 리스트·원고 (skills)
- `review-plan`: 장소/제품 조사 → 글 구성 → 촬영 리스트
- `review-write`: 사진·영상 보고 플랫폼별 원고 작성
- 이 단계만으로도 "원고 + 사진 정리"까지 자동

### Phase 3. 당근 스토리 업로드
- 영상 길이 맞춤 → 폰 갤러리에 넣기 → 앱에서 스토리 올리기 → 장소 태그 → 확인 후 게시

### Phase 4. 쿠팡 리뷰
- 앱(또는 PC) 리뷰관리 → 해당 상품 → 별점·본문·사진 → 확인 후 등록

### Phase 5. 네이버 블로그
- 앱/PC 중 안정적인 쪽 선택 → 제목·본문·사진·장소 → 임시저장 → 확인 후 발행

## 미정

- [x] PC OS: Windows
- [x] 폰: 안드로이드, 와이파이 전용 (유심 없음)
- [x] 당근: 개인 계정
- [ ] 당근 계정을 메인 폰과 같이 쓰면 기기 동시 로그인 가능 여부 확인
- [ ] 블로그 글 말투·길이 기준 (예전 글 링크 있으면 참고)

## 장기 목표: 앱 개발

| 단계 | 형태 | 난이도 |
|---|---|---|
| 1 | PC 에이전트 (지금 플랜) | 중 |
| 2 | 동반 앱: 촬영 리스트 보기·체크, 사진 전송, 원고 미리보기·승인 → 실제 업로드는 PC 에이전트 | 중 |
| 3 | 폰 단독 앱: 접근성 서비스(AccessibilityService)로 다른 앱 조작 + Claude API | 상 |
| 4 | 다른 사람에게 배포·판매 | 매우 상 (플레이스토어 정책, 플랫폼 약관, 대량 게시로 간주될 위험) |

- 1~3은 본인용이면 기술적으로 가능.
- 앱에서는 Claude Code 구독 대신 Claude API 키(사용량 과금)가 필요.
- 아이폰은 다른 앱 조작이 막혀 있어 3단계 불가.
