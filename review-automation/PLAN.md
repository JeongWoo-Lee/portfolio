# 후기 작성 자동화 플랜

## 대상

| 플랫폼 | 작업 | 공식 API | 작업 환경 |
|---|---|---|---|
| 네이버 블로그 | 후기 포스팅 | 없음 (2020.05 종료) | PC 웹 (스마트에디터 ONE) |
| 쿠팡 | 직접 구매한 제품 리뷰 | 없음 | PC 웹 (마이쿠팡 → 리뷰관리) |
| 당근 | 스토리 업로드 (5~60초 숏폼 영상) | 없음 | 모바일 앱 중심 (PC 웹 지원 확인 못 함) |

## 원칙

- 실행은 본인 PC에서 한다. 클라우드/데이터센터 IP는 차단 위험이 크다.
- 글 입력까지만 자동화하고, 최종 등록/발행 버튼은 사람이 누른다.
- 캡차·보안 인증은 우회하지 않는다. 뜨면 멈추고 사람이 처리할 때까지 기다린다.
- 직접 사용한 제품의 후기만 다룬다.
- 계정 정보·쿠키·세션 파일은 커밋하지 않는다 (`.gitignore`).

## 배경 (조사 결과)

- 네이버는 2025년 7월부터 댓글·공감·서이추 등 자동화 접근을 강하게 차단한다.
  글쓰기도 탐지될 수 있으므로, 자동화 전용 브라우저 대신 평소 쓰는 크롬에 연결하는 방식을 우선 검토한다.
- 일반 Playwright + 스텔스 플러그인은 탐지되는 경우가 많다.
- 쿠팡 구매자 리뷰를 자동 작성하는 공개 저장소는 찾지 못했다. 반자동(AI 초안 → 직접 붙여넣기)이 일반적이다.

## 단계

### Phase 1. 후기 초안 생성기 (공통)
- 입력: 사진/영상 폴더 + 짧은 메모(실사용 느낌) + 플랫폼
- 출력: 플랫폼별 텍스트
  - 네이버: 장문, 소제목, 사진 배치 순서
  - 쿠팡: 300~700자, 장단점·총평
  - 당근 스토리: 짧은 설명 문구
- 구현: Python + Claude API, 결과를 파일 저장 + 클립보드 복사
- 계정을 건드리지 않으므로 차단 위험 없음

### Phase 2. 네이버 블로그 반자동 등록
- Playwright를 평소 크롬 프로필에 연결(CDP)
- 제목·본문·사진 입력 후 **임시저장**까지만, 발행은 수동
- 모드: dry-run(입력만) → draft(임시저장)
- 에디터 셀렉터는 설정 파일로 분리 (네이버 에디터 구조가 자주 바뀜)

### Phase 3. 쿠팡 리뷰 반자동
- 리뷰관리 화면에서 별점·본문·사진 입력까지 자동화, 등록은 수동
- 쿠팡 봇 탐지 수준을 Phase 2 방식으로 먼저 검증

### Phase 4. 당근 스토리
- 앱 중심이라 두 가지 중 선택:
  - A. 반자동: 영상 길이 맞춤(5~60초) + 문구 생성 → 폰으로 전송 → 직접 업로드
  - B. 안드로이드 Appium/ADB로 앱 조작 (아이폰은 사실상 어려움)
- 기본은 A, 필요하면 B 검토

## 미정

- [ ] 당근: 개인 계정인가, 비즈프로필(가게) 계정인가
- [ ] 휴대폰: 안드로이드 / 아이폰
- [ ] PC OS: Windows / Mac
- [ ] AI 초안 사용 범위 (전체 생성 / 메모 다듬기만)
