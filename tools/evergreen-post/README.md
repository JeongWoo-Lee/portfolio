# evergreen-post

'연금형' 유튜브 채널을 찾아서, 왜 연금형인지 분석하는 X(트위터) 게시글 초안을 만든다.

연금형 = 몇 년 전에 올린 영상이 지금도 계속 조회수를 먹는 채널.
수면 음악, 백색소음, 공부 BGM처럼 **최신 영상을 볼 이유가 없는** 콘텐츠가 여기 해당한다.

```
주제어 "수면"
   │
   ├─ 1. 발굴   3년 넘은 영상 중 조회수 최상위를 검색 → 그 채널들을 후보로
   ├─ 2. 지표   채널별 상위 영상의 나이·조회수 분포로 연금 점수 계산
   ├─ 3. 캡쳐   동영상 탭을 인기순으로 정렬해 스크린샷        (로컬 전용)
   └─ 4. 초안   숫자를 근거로 게시글 3편 생성                  (Claude)
        │
        └→ out/2026-09-16_DeepSleepGuide/{metrics.json, post-1~3.txt, channel.png}
```

---

## 설치

```bash
pip install -r requirements.txt
playwright install chromium        # 스크린샷 쓸 때만

cp .env.example .env               # 키 채우기
export $(grep -v '^#' .env | xargs)
```

키는 두 개다. 둘 다 없어도 `demo`는 돈다.

| 키 | 용도 | 발급 |
|---|---|---|
| `YOUTUBE_API_KEY` | 데이터 수집 | [console.cloud.google.com](https://console.cloud.google.com) → YouTube Data API v3 사용 설정 → API 키. 무료 |
| `ANTHROPIC_API_KEY` | 초안 생성 | [console.anthropic.com](https://console.anthropic.com) → API Keys |

## 사용법

```bash
# 키 없이 파이프라인 확인
python3 run.py demo

# 주제어로 채널 발굴 → 상위 3개 채널의 초안 + 스크린샷
python3 run.py discover --topic 수면 --top 3

# 채널 하나만 지정해서 전체 실행
python3 run.py post --handle DeepSleepGuide

# 데이터만, 초안·캡쳐 없이
python3 run.py discover --topic "공부 집중" --no-draft --no-shot
```

주요 옵션: `--min-age`(기본 3년) `--min-subs`(기본 5만) `--candidates`(정밀 분석 후보 수) `--variants`(초안 개수) `--headful`(브라우저 창 띄우기)

## 연금 점수

0~100. **표준 지표가 아니라 이 도구가 정한 휴리스틱이다.** 가중치는 근거 있는 추정일 뿐 검증된 값이 아니므로, 총점보다 `metrics.json`의 `점수_구성`을 보고 직접 조정하는 걸 권한다. 가중치는 `score.py`의 `WEIGHTS` 한 곳에 모아뒀다.

| 구성요소 | 가중치 | 의미 | 만점 기준 |
|---|---|---|---|
| `age` | 0.35 | 상위 조회수 영상의 중앙값 나이 | 5년 이상 |
| `durability` | 0.30 | 최신 영상(1년 이내)에 안 기대는 정도 | 최신 의존도 0% |
| `reach` | 0.20 | 구독자당 조회수 — 검색/추천 유입 비중 | 구독자당 1000회 |
| `depth` | 0.15 | 100만 뷰 이상 영상 개수 | 100개 |

`age`와 `durability`가 이 지표의 본체다. `reach`·`depth`는 규모 보정에 가깝다.

참고로 fixture(브레이너 제이, 상위 6개 영상 기준)는 **81.2점**, 최근 영상이 조회수를 독식하는 가상의 '반짝 채널'은 **20.9점**으로 갈린다.

## API 할당량

YouTube Data API 기본 할당량은 하루 10,000 유닛이고, `search.list`만 100 유닛으로 유독 비싸다. 그래서 검색은 실행당 1회만 쓰고, 채널별 영상은 uploads 재생목록(50개당 1유닛)으로 긁는다.

```
검색 1회          100 유닛
채널 12개 메타       1 유닛
채널당 영상 300개   ~12 유닛 × 12 = 144 유닛
────────────────────────────
합계              ~245 유닛   → 하루 약 40회 실행 가능
```

실행할 때마다 실제 사용량이 출력된다. `--quota`로 예산을 걸면 초과 직전에 멈춘다.

## 초안 생성 방식

`draft.py`는 사용자가 제시한 참고 게시글의 **7단 구조**(훅 → 사례 → 숫자 증거 → 통찰 → 부연 → 일반화 → 열린 마무리)를 시스템 프롬프트로 인코딩한다.

핵심 안전장치 하나: **모델이 숫자를 만들어내지 못하게 막는다.** 프롬프트에 들어가는 모든 수치는 `score.Metrics.as_prompt_facts()`가 만든 JSON에서만 오고, 시스템 프롬프트가 "여기 없는 숫자는 쓰지 말라"고 명시한다. 표본이 채널 전체가 아니면 `데이터_불완전: true`가 함께 넘어가서 모델이 한정어를 붙이도록 돼 있다.

모델은 `claude-opus-5`, adaptive thinking + effort high. 정책 거절 시 `claude-opus-4-8`로 넘어가는 서버측 폴백을 켜뒀다(이 용도에서 거절날 일은 거의 없지만, 파이프라인이 조용히 빈 결과를 내는 것보다 낫다). 끄려면 `draft.py`의 `betas`/`fallbacks` 인자를 지우면 된다.

참고 게시글은 **문체 앵커로만** 쓴다. 프롬프트가 훅과 마지막 문장은 반드시 새로 쓰도록 지시하지만, 남의 글을 참고한 것이므로 초안은 그대로 올리지 말고 본인 문장으로 다듬어 쓰는 걸 권한다.

## 카드 이미지 (`card.py`)

유튜브 페이지에 접근하지 않고, 수집한 API 데이터만으로 첨부용 이미지를 그린다. HTML을 렌더한 뒤 로컬 Chromium으로 캡쳐하는 방식이라 `youtube.com`이 막힌 환경에서도 돌아간다.

```bash
python3 card.py     # fixture로 out/card-demo.png 생성
```

**이건 `capture.py`가 못 도는 환경을 위한 대체재이지, 실제 채널 페이지 스크린샷의 대체재가 아니다.** 원본 게시글처럼 진짜 유튜브 화면을 붙이고 싶으면 직접 찍는 게 맞다.

최초 실행 시 Noto Sans KR을 받아 `.fontcache/`에 캐시한다(약 18MB, gitignore 대상). 다운로드가 실패하면 시스템 폰트로 폴백한다. 이미지 높이는 산술 계산 대신 브라우저가 렌더 후 잰 `scrollHeight`를 쓴다 — 고정 높이를 손으로 계산하면 폰트 메트릭 차이로 아래가 잘린다.

## 알려진 제약

- **`capture.py`는 로컬에서만 된다.** Claude Code 클라우드 세션은 `youtube.com`이 네트워크 정책으로 차단돼 있다(`ERR_TUNNEL_CONNECTION_FAILED`). API 호출은 `youtube.googleapis.com`이라 별개로 잘 된다. 차단된 환경에서는 `card.py`로 대체할 수 있지만, **실제 채널 페이지 스크린샷이 필요하면 직접 찍는 수밖에 없다.**
- **정렬 칩 셀렉터는 깨질 수 있다.** 유튜브 DOM은 예고 없이 바뀐다. '인기순' 칩을 못 찾으면 `sort=p` URL 파라미터로 폴백하고 경고를 띄우는데, 이 파라미터가 최신 UI에서 계속 먹히는지는 확실하지 않다. 경고가 뜨면 결과 이미지의 정렬을 꼭 눈으로 확인할 것.
- **헤드리스는 봇 감지에 걸릴 수 있다.** 빈 페이지가 나오면 `--headful`로 실행.
- **발굴 품질은 주제어에 좌우된다.** 검색 결과가 그대로 후보가 되므로, 주제어가 넓으면(`음악`) 관련 없는 채널이 섞인다. 좁고 구체적인 주제어(`수면 유도 음악`, `공부 백색소음`)가 낫다.
- **X 자동 게시는 없다.** 의도적으로 뺐다. 초안은 파일로만 나온다.
